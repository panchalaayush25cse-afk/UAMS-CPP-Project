3. Activity Diagram: Binary File Persistence & Random Update

flowchart TD
    Start(["⚫ Start"]) --> Input["Receive Student Academic Details"]
    Input --> Calc["Calculate Percentage via Inline Function"]
    Calc --> Pack["Pack into StudentBinaryRecord struct"]
    Pack --> FileOpen{"Open students.dat\nin binary mode?"}
    FileOpen -- Yes --> Write["write() reinterpret_cast to File"]
    FileOpen -- No --> Err["Display File Stream Error"]
    Write --> Close["Flush & Close File Stream"]
    Close --> Search["Search by ID Request"]
    Search --> Seek["Iterate with tellg() and read()"]
    Seek --> Match{"Record ID\nMatches?"}
    Match -- Yes --> Modify["Update Record Percentage"]
    Modify --> SeekP["seekp(-sizeof, ios::cur)\nReposition Write Pointer"]
    SeekP --> WriteBack["write() Updated Structure"]
    Match -- No --> ReadNext["Read Next Block"]
    ReadNext --> Seek
    WriteBack --> Finish(["⚫ End"])
    Err --> Finish

4. Sequence Diagram: Runtime Polymorphic Reporting

sequenceDiagram
    autonumber
    actor User as User / Admin
    participant Main as main() Menu
    participant Array as ReportableEntity* Array
    participant Stu as Student Object
    participant Fac as Faculty Object
    participant TA as TeachingAssistant Object

    User->>Main: Select Option 1
    Main->>Array: Initialize base pointer array
    Array->>Stu: campusEntities[0] = &st1
    Array->>Fac: campusEntities[2] = &prof
    Array->>TA: campusEntities[3] = &ta

    loop For each entity in campusEntities[]
        Main->>Array: campusEntities[i] -> displayDetails()
        alt i == 0 or 1 → Student
            Array->>Stu: Dynamic dispatch → Student::displayDetails()
            Stu-->>Main: Print Student academic record
        else i == 2 → Faculty
            Array->>Fac: Dynamic dispatch → Faculty::displayDetails()
            Fac-->>Main: Print Faculty profile
        else i == 3 → TeachingAssistant
            Array->>TA: Dynamic dispatch → TA::displayDetails()
            TA-->>Main: Print TA details
        end
    end
    Main-->>User: Complete formatted output table

5. State Diagram: Student Fee Account Lifecycle

stateDiagram-v2
    [*] --> AccountCreated : Admission Accepted
    AccountCreated --> FeePending : Initial Fee Assessed
    FeePending --> PartiallyPaid : Partial Payment Received
    FeePending --> Cleared : Full Lump sum Paid

    PartiallyPaid --> Cleared : Final Payment (balance == 0)
    Cleared --> RefundProcessed : Excess Fee Withdrawn
    Cleared --> [*] : Academic Term Concluded
    RefundProcessed --> [*]
